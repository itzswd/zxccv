# Fruit Ninja - Полный промпт для воссоздания игры

## Основные требования
Создать полную копию игры "Fruit Ninja" с:
- Реалистичной графикой фруктов (НЕ использовать эмодзи/смайлики)
- Деревянным фоном как в оригинальной игре
- Следами от разрезания фруктов (брызги сока на фоне)
- 3 уровня сложности (Легко, Средне, Сложно)
- Комбо-системой
- Минималистичным интерфейсом с закругленными краями
- Плавными анимациями
- Следом от лезвия при свайпе

## Технические требования
- React + TypeScript + Vite + Tailwind CSS
- Canvas API для рендеринга игры
- Web Audio API для звуковых эффектов
- LocalStorage для сохранения данных

## Реализованные функции

### 1. Игровая механика
- Фрукты вылетают снизу экрана с разной скоростью
- Физика: начальная скорость `vy: -(Math.random() * 6 + 18)`, гравитация `0.32`
- Разрезание фруктов свайпом мыши/пальца
- 3 жизни (пропуск фрукта = -1 жизнь)
- Бомбы (разрезание = мгновенная смерть)
- Комбо-система (множитель очков до x8)

### 2. Система монет и магазин
- Монеты начисляются за разрезанные фрукты (очки / 10)
- Магазин с 6 стилями лезвия:
  - Обычное (бесплатно) - белый след
  - Ледяное (100 монет) - голубой
  - Мистическое (200 монет) - фиолетовый
  - Огненное (300 монет) - красный
  - Золотое (500 монет) - золотой
  - Радужное (1000 монет) - меняет цвета
- Данные сохраняются в localStorage

### 3. Визуальные эффекты
- След от лезвия с эффектом свечения
- Брызги сока при разрезании фруктов
- Половинки фруктов разлетаются в стороны
- Частицы для эффектов
- **Порезы на деревянном фоне** - острые треугольники (ромбы) с заостренными концами
- Разная длина порезов (30-150 пикселей)
- Острые края (не закругленные!)

### 4. Звуковые эффекты
- Звук разрезания
- Звук свайпа
- Звук бомбы
- Звук комбо

## Ошибки и их решения

### 1. Зелёный фон у фруктов
**Проблема**: Изображения фруктов имели зелёный фон
**Решение**: 
- Генерировать изображения с белым фоном
- Функция `removeBackground()` удаляет белый фон через canvas
- Fallback если CORS блокирует обработку

### 2. Лаги после разрезания фрукта
**Проблемы**:
- `Math.random()` вызывался в цикле рендеринга splatters
- Фон перерисовывался каждый кадр
- Не было лимита на количество частиц

**Решения**:
- Предрассчитывать форму splatters в массиве `shape: number[]`
- Кешировать фон в offscreen canvas (`bgCache`)
- Ограничить частицы (max 200) и splatters (max 50)
- Ограничить woodScratches (max 30)

### 3. Ошибка "Cannot access 'game' before initialization"
**Проблема**: Переменная `game` использовалась в функции `resize` до объявления
**Решение**: Переместить `const game = gameRef.current;` перед функцией `resize`

### 4. Ошибка "arc with negative radius"
**Проблема**: `ctx.arc(p.x, p.y, p.size * alpha, ...)` мог получить отрицательный радиус
**Решение**: `const radius = Math.max(0, p.size * alpha);` и проверка `if (radius > 0)`

### 5. CSP ошибки
**Проблема**: Inline `<script>` теги в index.html нарушали Content Security Policy
**Решение**: Убрать все inline скрипты, оставить только необходимый минимум

### 6. Порезы были закругленными
**Проблема**: `lineCap = 'round'` делал концы линий закругленными
**Решение**: Рисовать порезы как треугольники (ромбы) с острыми концами через `ctx.beginPath()` и `ctx.fill()`

## Настройка параметров

### Чтобы фрукты летели выше:
- Увеличить `vy` (например, до `-25`)
- Уменьшить `gravity` (например, до `0.25`)

### Чтобы фрукты падали быстрее:
- Увеличить `gravity` (например, до `0.45`)

### Для "лунной" физики:
- Маленький `vy` (например, `-12`)
- Маленький `gravity` (например, `0.15`)
